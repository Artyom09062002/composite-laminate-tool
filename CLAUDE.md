# Independent Review Brief

Review this project as an independent composite-mechanics reviewer. Do not assume that implementation is correct. Audit:

1. `Q` and `Q-bar` transformations, including engineering-shear conventions;
2. ply angle and through-thickness coordinate signs;
3. ABD assembly, units, symmetry and numerical stability;
4. tests and the traceability of material reference data.

Report each issue with engineering reasoning before suggesting a code change. Do not replace validated equations merely for style or abstraction.
