# R0b independent thermal and optimiser review

Reviewed 7 October 2026. Read AGENTS.md, SPEC.md, ACCEPTANCE.md, STATE.md and the smart-model-router skill before reviewing. Scope: core/thermal.py and core/optimise.py. No mechanics equations, material defaults or numerical snapshots changed.

Numerical evidence was obtained with the existing `.venv/Scripts/python.exe` through Desktop Commander, running independent Python probes from standard input. The probe process printed `ALL INDEPENDENT PROBES PASSED`. The regular exec runner intermittently failed before launching commands; this did not prevent these probes. These checks establish numerical consistency for the cases below, not experimental validation or certification.

1. **P1 equation concern — rejected: CTE shear transform.** Independently form the local symmetric tensor `[[alpha1, alpha12/2], [alpha12/2, alpha2]]`, rotate it as `R T R.T`, and extract `[Txx, Tyy, 2 Txy]`. Seven angles (-90, -57, -15, 0, 31, 45, 90 degrees), including nonzero engineering shear CTE, agreed with `transform_cte` to a maximum absolute error of 3.3881317890172014e-21 /K. The inverse strain rotation in the implementation is correct for material-to-global rotation and positive CCW ply angles.

2. **P1 equation concern — rejected: thermal force/moment signs and units.** For uniform ply eigenstrain, `N_T=sum(Qbar alpha_bar dT dz)` and `M_T=sum(Qbar alpha_bar dT (z1^2-z0^2)/2)`. These are equivalent eigenstrain loads. Actual stress resultants are `ABD [epsilon0,kappa] - [N_T,M_T]`; zero external load therefore uses the positive right-hand-side thermal vector. N has units N/m and M has units N. The module documentation and implementation agree.

3. **P1 equation concern — rejected: stress-free off-axis ply.** A single 31-degree T300/5208 ply, thickness 0.125 mm, delta T=-100 K and deliberately nonzero alpha12=4.4e-6 /K recovered maximum absolute local stress 9.008215283701962e-9 Pa. Free extension/shear accommodates its eigenstrain; the result rejects an erroneous stress/strain shear-factor combination.

4. **P1 equation concern — rejected: cooling residual sign.** The sourced T300/5208 [0/90]s stack at delta T=-100 K recovered positive transverse tensile stress +21.266498873485293 MPa in a 0-degree ply. Maximum absolute curvature was 4.083388406917629e-17 /m. This is consistent with bonded cross-ply mismatch under cooling and symmetry.

5. **P1 equation concern — rejected: recovered unsymmetric equilibrium.** Independently rotate recovered local stresses as second-order stress tensors. Integrate the linearly varying surface stresses exactly: force `(z1-z0)(sigma_bottom+sigma_top)/2`; moment `(z1-z0)[(2z0+z1)sigma_bottom+(z0+2z1)sigma_top]/6`. A 31-degree carbon / -17-degree glass / 90-degree carbon hybrid with unequal thicknesses at delta T=-100 K produced absolute force components <=3.751665644813329e-12 N/m and moment components <=4.163336342344337e-16 N. Both force and moment equilibrate independently of the thermal-resultant code path.

6. **P1 convention concern — rejected: reversed-stack curvature.** Reversing that hybrid preserved midplane strain to 1.1384122811097797e-18 and negated curvature to 6.217248937900877e-15 /m. This agrees with bottom-to-top z ordering, B and thermal moment sign reversal.

7. **P2 interpretation concern — rejected in current UI: cure equals stress-free temperature.** `temperature_change_from_reference(121.11111111111111,-196)` returned -317.1111111111111 K. The helper uses final minus reference, without asserting provenance. The UI explicitly requests an assumed common stress-free temperature and says individual material references do not establish a co-cured hybrid reference. Material records distinguish the NASA approximation from nominal cure and the Scotchply assumed press-cure reference from a measured stress-free temperature. Source documents were not independently reverified in this review; constant-property cryogenic predictions remain model extrapolations.

8. **P1 implementation concern — rejected: optimiser determinism.** An eight-ply run with six angles, budget 30, seed 987 returned identical full result objects when allowed angle order was reversed. The global `random` state was unchanged. All 30 candidates were unique, eight physical plies long, symmetric, and drawn from the allowed angles. Sorted angle canonicalisation, local `Random(seed)` and explicit ranking keys support reproducibility. This was a bounded numerical check, not proof over all possible inputs.

9. **P1 implementation concern — rejected: fixed-mass and odd single-angle handling.** Every evaluated candidate retained the same material, physical ply count and individual thickness. Thus rho*n*t per wall area is fixed without inventing density. Single-angle [-90] runs for odd physical ply counts 1, 3 and 9 returned exactly that angle in all plies. Symmetric count search intentionally excludes arbitrary ordering and nonsymmetric candidates.

10. **P1 physical interpretation concern — rejected in current core: netting optimum.** Independently derive axial/hoop projections for a balanced single-angle wall: `p <= min(2 Xt h cos^2(theta)/R, Xt h sin^2(theta)/R)`. Equality of the projections gives tan^2(theta)=2 and p=2 Xt h/(3R). For Xt=1500 MPa, h=1 mm, R=0.15 m, both oracle and optimiser best fibre projection were 6,666,666.666666667 Pa. This is a fibre-only projection bound, with exact netting equilibrium separately available for balanced stacks. It is not an upper bound on matrix-bearing CLT and does not prove an optimum for first-ply or progressive stopping pressure.

11. **P2 search interpretation — confirmed limitation, already disclosed.** Small spaces are exhausted; larger spaces are anchored, seeded samples with deterministic fallback. Search radius, angle restrictions, count symmetry, sampling budget and separate first-/last-ply rankings must accompany an optimiser result. An exhaustive count space is not a continuous or global manufacturing optimum. Current module documentation states this limitation.

**Disposition:** No confirmed thermal or optimiser equation error. No core or snapshot modification is justified by these findings. Independent probes supplement the existing regression suite; no new persisted test was needed because the accepted mechanics were unchanged.
