# C4: independent review of `core/failure.py` (Hashin) and `core/progressive.py` — verification of each comment

Each comment was checked by derivation or by running the code before any change. Scripts were run against the pre-change code; the checks
that matter are now regression tests in `tests/test_review_c4.py`. The Hashin initiation formulas and the load-factor solver were not changed.
The reviewer's literature remarks (NASA review pp. 34–37, "53° as a Puck/Hashin rule") were **not** checked against the sources by me; where a verdict
depends on them it says so.

Verdicts: **Confirmed** = the defect exists as described; **Confirmed, wording** = the numbers are right but the claim in the code, UI or docs was
stronger than the model supports; **Partly confirmed**; **Rejected** = no defect (or no change is justified).

## Further findings from this review (not in the reviewer's list)

* The default St exceeds S12 for T300/5208 (92.7 vs 68 MPa) and for the Alam card (109 vs 96.5 MPa); see item 3.
* Unsymmetric walls: with free-plate CLT the wall curves, which a restrained vessel wall does not. For the 12-ply Kangal stack the last-ply value moves from 64 to 243 bar with the (unsourced) stack order while netting stays at 242 bar (`validation/README.md`). Reversing a whole stack gives identical results (mirror image), so it is not a sensitivity.

## Rejected, or not acted on (with reasons)

* **Item 2, alternatives "do not activate FT at small sigma1" and "use alpha = 0":** not adopted. Both weaken or change the initiation criterion (a state such as sigma1 = 0.5 Xt, tau12 = 0.9 S is a failure by Hashin 1980 with alpha = 1). The fix changes only what is degraded, not when the ply fails.
* **Item 5, separate calibrated rules for FT, FC, MT and MC:** not implemented. No calibration data exist in the project; more free parameters would suggest precision the model does not have. The residual-factor range is reported instead.
* **Item 7, replacing the termination rule by a damage-evolution law with fracture energy and a characteristic length:** out of scope for a screening model; the rule is renamed and its status stated.
* **Item 9, displacement control, arc-length and a stability criterion:** not implemented; the limitation is stated and held steps are flagged.
* **Item 11, "the result depends on splitting a physical ply":** not reproduced for the load factors (identical for 1, 2, 3, 4 and 8 sub-plies in the cases tried); only the event and step counts change. Stated as a limit, not as a defect.
